# Remaster NOVA homepage as a soft premium studio

## Scope
- Replace only the public homepage with one long, responsive experience; keep the existing app, authentication, routes, and dashboard unchanged.
- Reframe the requested studio aesthetic around NOVA’s real positioning: AI marketing intelligence for youth-focused brands.

## Homepage structure
- Add a sticky rounded navigation with desktop anchors, a mobile menu, and a clear “Request access” action.
- Build a spacious opening section with the NOVA value proposition, subtle floating clay-style objects, calls to action, and an original trusted-by logo row.
- Add service cards for trend intelligence, content strategy, and brand voice.
- Add an interactive case-study carousel with a strong center slide and faded neighboring slides.
- Add mission and company-story cards, an asymmetric benefits grid, a vertical six-step process, a varied portfolio gallery, two pricing plans, testimonials, FAQ, and a rounded multi-column footer.

## Visual direction
- Make the homepage light-first with an off-white diagonal-line texture, near-black navy text, and restrained lavender, blue, blush, yellow, and mint accents.
- Use Instrument Sans, large rounded cards, translucent borders, soft colored shadows, subtle gradients, and lightweight hover motion.
- Use original generated campaign artwork and CSS-built clay-style decorations; no copied brands, logos, or imagery.
- Preserve semantic color tokens and ensure the existing dark application remains unaffected.

## Technical details
- Split reusable homepage pieces into focused components for navigation, cards, pricing, testimonials, FAQ, carousel, and footer.
- Keep all navigation links functional, add keyboard-accessible carousel controls and mobile navigation, and respect reduced-motion preferences.
- Update homepage metadata and load Instrument Sans through the document head.
- Verify the homepage at desktop and mobile widths, including menu and carousel interactions, and confirm no runtime or build errors.
